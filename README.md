# PixelWork

> **AI와 함께 픽셀아트를 정밀하게 깎아나가는 경량 스프라이트 인스펙터 & 협업 워크플로**

**PixelWork**는 2D 도트 게임의 스프라이트 아틀라스와 애니메이션을 검수하고, 어색한 부위를 직관적으로 표시하여 AI(Gemini)와 함께 국소 단위로 교정(Micro-patching)하기 위한 로컬 웹 인스펙터 도구입니다.

---

## 💡 개발 배경 & 철학

기존 생성형 AI로 픽셀아트를 작업할 때 흔히 겪는 문제들이 있습니다:
1. **수식/비례로 한 번에 고치려다 도트가 붕괴됨**: 24×32 같은 초저해상도 도트는 연속된 인체 비례가 아니라 1픽셀의 생략과 배치가 핵심입니다.
2. **저해상도 원본 인식 한계**: AI 비전 모델은 너무 작은 이미지(24×32)를 통째로 보면 블러나 노이즈로 오인하여 디테일을 읽지 못합니다.
3. **앞/뒤 깊이(레이어) 혼동**: 걷기나 달리기 모션에서 팔/다리의 앞뒤 원근을 헷갈려 신체 부위가 몸통을 뚫고 나오는 등의 오류가 생깁니다.

**PixelWork는 다음 원칙으로 이 문제를 해결합니다:**
- **전체 재생성 금지, 국소 영역 패치**: 수정이 필요한 특정 사각 영역(`bbox`)만 지정하여 픽셀을 정밀하게 교정합니다.
- **16배 선명 확대 듀얼 비전 뷰**: AI에게 16배 Nearest-Neighbor 전체 뷰와 픽셀 좌표 격자가 찍힌 마이크로 줌 뷰를 공급하여 정확한 시각적 이해를 돕습니다.
- **외부 툴과의 유기적 연동 (Hot Reload)**: Aseprite, Photoshop 등에서 작업한 아틀라스를 저장하면 브라우저가 변경 사항을 즉시 감지하여 실시간 반영합니다.

---

## ✨ 주요 기능

- **동적 규격 지원 (No Hardcoding)**: 
  - 특정 해상도에 고정되지 않고, 상단 UI에서 원하는 소스 파일 경로와 프레임 크기(W, H)를 지정하여 슬라이스할 수 있습니다.
- **실시간 모션 플레이어**:
  - **밀리초(ms) 단위 딜레이 설정**: FPS 대신 직관적인 프레임 지연 시간(ms) 입력 및 슬라이더 제공.
  - **어니언 스킨 (Onion Skin)**: 이전 프레임을 반투명하게 겹쳐 모션의 연결성을 실시간 확인.
  - **키보드 단축키**: `←` / `→` (프레임 단위 이동), `Space` (재생 / 정지).
  - **확대 배율(Zoom) 선택**: 8x, 12x, 16x(기본), 20x, 24x, 32x 지원.
- **AI Task Dispatch & 인스펙션 뷰**:
  - 캔버스에서 마우스 드래그로 어색한 영역을 지정하고 지시사항 작성.
  - AI 작업 등록 시 16배 확대 컨텍스트 뷰 + 마이크로 격자 뷰가 자동 생성되어 AI에게 전달.
- **외부 수정 자동 감지 (Hot Reload)**:
  - 소스 파일(`src/*.png`)의 수정 시간(`mtime`)을 감지하여 브라우저 새로고침 없이 캔버스와 애니메이션을 즉각 갱신.

## 🚀 빠른 시작

### 1. 요구사항
- Python 3.10 이상
- `Pillow`

```bash
pip install pillow
```

### 2. 서버 실행
```bash
python server.py
```
브라우저에서 [http://localhost:8088/](http://localhost:8088/) 접속.
