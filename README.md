# PixelWork

> **AI와 함께 픽셀아트를 정밀하게 깎아나가는 초경량 로컬 스프라이트 인스펙터 & 협업 워크스페이스**

**PixelWork**는 2D 도트 게임의 스프라이트 아틀라스와 애니메이션을 정밀하게 검수하고, 어색한 부위를 마우스 드래그로 직관적으로 지정하여 AI(Gemini)와 함께 국소 단위로 교정(Micro-patching)하기 위한 로컬 웹 스튜디오입니다.

---

## 💡 개발 배경 & 철학

기존 생성형 AI로 픽셀아트를 작업할 때 흔히 겪는 문제들이 있습니다:
1. **전체 재생성 시 도트 붕괴**: 24×32 같은 초저해상도 도트는 인체 비례 수식이 아닌 1픽셀 단위의 생략과 배치가 생명입니다. 전체를 다시 그리면 기존 도트 스타일이 뭉개집니다.
2. **저해상도 원본 인식 한계**: AI 비전 모델이 24×32 원본 이미지를 통째로 보면 블러나 압축 노이즈로 오인하여 미세한 디테일을 분간하지 못합니다.
3. **레이어 전후 관계 왜곡**: 모션 프레임 간 팔/다리의 앞뒤 원근을 혼동해 신체 부위가 몸통을 뚫고 나오는 등의 버그가 발생합니다.

**PixelWork는 다음 원칙으로 이 문제를 해결합니다:**
- **전체 재생성 금지, 국소 영역 패치 (Micro-patching)**: 수정이 필요한 특정 사각 영역(`bbox`)만 지정하여 원본 화풍을 유지한 채 픽셀 매트릭스를 정밀 교정합니다.
- **16배 선명 확대 듀얼 비전 검수 뷰**: AI에게 16배 Nearest-Neighbor 전체 컨텍스트 뷰와 픽셀 좌표 격자가 찍힌 마이크로 줌 뷰를 함께 제공하여 정확한 시각적 이해를 보장합니다.
- **정확한 메타데이터 전송**: 단순 좌표뿐만 아니라 현재 선택이 일어난 **트랙명**과 **프레임 번호**가 함께 바인딩되어 AI에게 명확한 문맥을 전달합니다.

## ✨ 핵심 기능

### 1. 직관적인 스프라이트 로드 & 동적 슬라이싱
- **로컬 파일 직접 선택 & 업로드**: UI 상단의 `📁 파일 선택...` 버튼을 통해 작업 중인 아틀라스 이미지(PNG, JPEG, WebP)를 즉시 업로드하고 분석할 수 있습니다.
- **동적 규격 지원 (No Hardcoding)**: 특정 규격에 종속되지 않고, 프레임 가로(W) / 세로(H) 크기를 자유롭게 입력하여 동적으로 아틀라스를 슬라이스합니다.

### 2. 고성능 렌더링 & 무지연 플레이어
- **메모리(RAM) 프리로딩 기반 0ms 반응**: 아틀라스 로드 시 모든 트랙과 프레임을 브라우저 메모리에 즉시 캐싱하여, 일시정지 상태나 트랙 전환 시에도 네트워크/디스크 지연 없이 0ms 즉각 반응합니다.
- **HiDPI 정수 스케일링 & 픽셀 뭉개짐(Blur) 완벽 방지**:
  - Windows의 125%/150% 배율 등 고해상도 모니터 환경에서 발생하는 서브픽셀 왜곡(톱니 지터 현상)을 정수 스케일링 버퍼로 해결했습니다.
  - HTML5 캔버스의 `imageSmoothingEnabled = false` 강제 재적용을 통해 1배부터 32배까지 칼같은 선명도를 유지합니다.
- **자유 배율 조정 (1x ~ 32x)**: 드롭다운 대신 1배부터 32배까지 원하는 배율을 자유롭게 숫자로 직접 입력합니다.
- **밀리초(ms) 단위 프레임 지연 조절**: 직관적인 ms 단위 입력으로 자연스러운 프레임 타이밍을 조절합니다.
- **어니언 스킨 (Onion Skin) & 격자 (Grid)**: 이전 프레임을 반투명하게 겹쳐 모션의 연결성을 실시간으로 확인하고, 픽셀 단위 격자를 켜고 끌 수 있습니다.
- **캔버스 실시간 재생 표시 배지**:
  - 애니메이션 재생 시 캔버스 좌상단에 `▶ 재생 중` 플로팅 인디케이터 배지가 나타나 재생 상태를 명확히 안내합니다.
  - 배지를 클릭하거나 `Space` 키를 눌러 손쉽게 일시정지할 수 있습니다.

### 3. 작업 환경 맞춤형 듀얼 레이아웃 (피벗 모니터 지원)
상단 드롭다운을 통해 작업 환경에 최적화된 레이아웃을 선택할 수 있으며, 설정은 브라우저에 자동 저장됩니다:
- **🖥️ 가로형 (기본)**: 좌측(트랙/플레이어) - 중앙(메인 캔버스) - 우측(수정 요청 & 인스펙션 뷰) 3열 구조.
- **📱 세로형 (피벗 모니터)**: QHD 세로 모니터 사용자를 위한 전용 레이아웃.
  - **1순위 (상단)**: 큼직한 메인 캔버스 뷰
  - **2순위 (중단)**: AI 수정 요청 폼(가변 너비)과 16배 비전 검수 뷰(380px 고정 너비)가 나란히 2열 배치되어 여백 없이 최적의 시야 확보
  - **3순위 (하단)**: 애니메이션 트랙 목록 및 실시간 모션 플레이어 2열 그리드 배치

### 4. AI 수정 피드백 루프 & 실시간 동기화
- **마우스 드래그 영역 지정**: 캔버스에서 어색한 부위를 마우스로 드래그하면 선택 영역 좌표와 트랙/프레임 정보가 자동 입력됩니다.
- **16배 비전 인스펙션 뷰 자동 생성**: 수정 요청 전송 시 전체 컨텍스트 뷰와 마이크로 좌표 격자 뷰가 생성되어 전송 상태를 검수할 수 있습니다.
- **버전 감지 기반 실시간 자동 갱신 (Auto-Refresh)**: AI가 수정을 완료하면 버전 번호가 자동 감지되어 브라우저 새로고침 없이 최신 아틀라스가 화면에 즉각 반영됩니다.

### 5. 키보드 단축키
| 단축키 | 동작 |
| :--- | :--- |
| <kbd>Space</kbd> | 애니메이션 재생 / 일시정지 토글 |
| <kbd>←</kbd> | 이전 프레임 이동 |
| <kbd>→</kbd> | 다음 프레임 이동 |
| <kbd>ESC</kbd> | 캔버스 선택 영역 해제 |

## 🤝 AI 협업 가이드 (Human-in-the-Loop)

1. 웹 스튜디오([http://localhost:8088/](http://localhost:8088/))에서 아틀라스를 로드하고 모션을 재생합니다.
2. 어색한 모션이나 튀어나온 픽셀이 있는 프레임에서 정지하고, 캔버스 위를 마우스로 드래그합니다.
3. 수정 요청 입력창에 요청사항(예: *"3번 프레임에서 뒷팔이 몸통 앞으로 튀어나와 있음. 몸통 뒤 레이어로 넘겨줘"*)을 적고 전송 버튼을 누릅니다.
4. AI에게 채팅으로 **"방금 보낸 작업 진행해줘"**라고 요청하면, AI가 인스펙션 뷰를 확인하여 해당 픽셀을 정밀 교정한 뒤 아틀라스를 업데이트합니다.
5. 웹 화면에 즉각적으로 반영된 결과를 확인합니다.
